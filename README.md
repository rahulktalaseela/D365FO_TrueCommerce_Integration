The S’well API framework integrates with TrueCommerce EDI to automate the exchange of 850 (Purchase Orders), 856 (Advance Ship Notices), and 810 (Invoices). The integration uses custom connectors and EDI mapping classes—such as TC850Processor, TC856Parser, and TC810Dispatcher—to transform EDI files into D365-ready JSON payloads, which are then posted into Microsoft Dynamics AX/D365 through the S’well API layer for automated order, shipment, and invoice creation
